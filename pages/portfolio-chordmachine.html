Chord Machine CM-01

Chord Machine CM-01 is a self-initiated web app built from a personal need to better understand piano chord theory as a music producer. Created as an experiment in agentic AI assistant development using Claude Sonnet 4.6 and OpenAI Codex, the app turns chord exploration into an intuitive, hardware-inspired experience. Users can explore all 24 major and minor chords, hear them instantly via the Web Audio API, and navigate harmony through a Mood Map organized by emotional feel. A progression queue allows for building, looping, and saving sequences, with full MIDI support for external controllers. Built entirely in vanilla HTML, CSS, and JavaScript with no frameworks, it showcases a strong focus on audio programming, and creative tooling.

Desktop browser only.
