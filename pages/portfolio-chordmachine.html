Chord Machine CM-01

Chord Machine CM-01 is a self-initiated web app born from a simple personal need: I wanted to understand piano chord theory as a music producer but couldn't find a tool that spoke my language, so I built one. I used the project as a hands-on experiment in AI-assisted development, working with Claude Sonnet 4.6 via Claude Code and OpenAI Codex directly in my IDE to explore how these models think through design and engineering problems differently. The app lets producers explore all 24 major and minor chords, hear them instantly, and navigate emotion through a Mood Map that plots every chord by feel rather than theory. A progression queue lets you build, loop, and save chord sequences, and full Web MIDI support means your controller works out of the box. Built entirely in vanilla HTML, CSS, and JavaScript with the Web Audio API handling sound synthesis and the Web MIDI API handling hardware, no frameworks, no dependencies.
